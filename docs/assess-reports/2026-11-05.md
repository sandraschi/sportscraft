## Findings before the fix

### CRITICAL

**C1 — `sportscraft-mcp` is not an MCP server (`crates/sportscraft-mcp/src/main.rs`).**
It had no stdin loop, no `initialize`, no `tools/list`, no `tools/call`, and no
JSON-RPC framing. Running it with an `initialize` request on stdin produced a
banner and exit code 0:

```
[sportscraft-mcp] Initializing Sports Biomechanics FastMCP engine on port 14131...
[sportscraft-mcp] Status: { ... "status": "ready", "capabilities": [...] }
EXIT=0
```

It advertised four capabilities it could not serve, and `README.md` claimed
"FastMCP Protocol: Exposed on port `14131`" while binding nothing. This is the
fleet's "stub described as complete" failure, not a missing feature. (§1W R5;
`AGENTS.md` §9.)

### HIGH

**H1 — clippy gate failed.** `cargo clippy --workspace --all-targets
--all-features -- -D warnings` reported 2 errors: `new_without_default`
(`sportscraft-app/src/main.rs:26`) and `collapsible_if` (`main.rs:225`). The §1W
gate block says any FAIL is HIGH.

**H2 — fmt gate failed.** `cargo fmt --check` produced diffs in
`crates/sportscraft-app/src/cli.rs` and `src/main.rs`.

**H3 — containment denies missing (R1).** `#![deny(unwrap_used, expect_used,
panic, todo, unimplemented)]` existed only in `sportscraft-core/src/i18n.rs`.
The workspace `Cargo.toml` had no `[workspace.lints.clippy]`, and the other three
crates had no `#![deny(...)]` blocks or `[lints] workspace = true`.

**H4 — fake UI actions.** File → "Export Pacing Strategy to PDF..." and "Sync
FIT/GPX Telemetry" only assigned a status string (`main.rs:54-61`). No file was
written, no telemetry was read. Both were advertised as working menu items.

**H5 — fake authentication.** The "Basic Auth Login" modal accepted any non-empty
username with any password (`main.rs:225-231`) and gated nothing; the password
field was never compared to anything. It was labelled "Authenticate for Biometric
& Telemetry Access".

**H6 — i18n was dead code.** `AppLocale` (7 locales) and a 14-key translation
table existed, but `i18n::t` was never called. Changing the locale selector only
changed the selector's own label; every other string was hardcoded English, while
CHANGELOG claimed "fleet-standard i18n localization (EN, DE, FR, ES, JA, KO, ZH)".

**H7 — README/About claims were false.** "FastMCP Protocol on port 14131";
"database session storage, and workout queue" (no storage or queue code); "Subsumes
TrainingPeaks, GoldenCheetah, and Stryd" (About dialog).

### MEDIUM

- **M1 (R2)** — no `justfile`; every gate had to be run by hand.
- **M2 (R4)** — no `Command::dispatch` bus; CLI, MCP, and UI each called the engine
  directly, so surfaces could (and did) drift.
- **M3** — no `CHANGELOG.md` (6-gate bar item 6).
- **M4 (Phase 5R)** — no `installer/installer.nsi`; no release installer existed.
- **M5** — `reports/` was not in `.gitignore`.
- **M6** — Banister TSB semantics were broken: `fatigue_weight_k2 = 1.8` put ATL on
  a different scale from CTL, so TSB settled near `−0.8 × CTL` (the demo profile
  reported **−116.9**) and the advertised `+5 .. +18` race-ready window was
  unreachable in any training pattern.
- **M7** — tests: 2 only, both happy-path; no dispatch, catalog, validation, taper,
  or i18n coverage.
- **M8** — no `LICENSE-MIT` / `LICENSE-APACHE` despite `license = "MIT OR
  Apache-2.0"`.
- **M9 (R7)** — no visual-parity evidence (`docs/parity/**`).

### LOW

- `AGENTS.md` missing; no `docs/` (so R9 version convention undocumented).
- No `HANDOVER.md` (R10).

## What was fixed in this run

### CRITICAL

- **C1** — `sportscraft-mcp` is now a real MCP `2024-11-05` stdio server:
  `initialize`, `notifications/initialized`, `tools/list`, `tools/call`, `ping`,
  parse errors as `-32700`, unknown methods as `-32601`. Stdout is JSON-RPC only;
  logs go to stderr. Four tools are registered and backed by real code
  (`status`, `athlete.profile`, `athlete.predict`, `gait.analyze`), with dotted and
  underscore aliases routing to the same arm. The false port claim was removed from
  code, README, and About.

### HIGH

- **H1/H2** — added `impl Default for SportsCraftApp`, collapsed the nested `if`,
  and ran `cargo fmt --all`. Both gates now pass.
- **H3** — added `[workspace.lints.clippy]` (deny `unwrap_used`, `expect_used`,
  `panic`, `todo`, `unimplemented`), `[lints] workspace = true` in all four crates,
  and the matching `#![deny(...)]` block in every `lib.rs` / `main.rs`. The lints
  immediately caught two `.expect()` calls in my new tests, which were rewritten —
  the gate is live, not decorative.
- **H4** — File menu now offers "Export Pacing Plan (JSON)", which writes
  `sportscraft-pacing-<distance>m.json` and reports the real path, and "Copy Pacing
  Plan", which puts real JSON on the clipboard. The unimplemented PDF and FIT/GPX
  entries were deleted rather than left as pretend features.
- **H5** — the fake auth modal and the `is_authenticated` gate were removed.
  README and About now state there is no authentication.
- **H6** — every UI string goes through `i18n::t`; 27 UI keys were added in all
  seven locales, so the selector actually changes the interface.
- **H7** — README and About rewritten to claim only what exists, including an
  explicit "What is not implemented" section (no FIT/GPX import, no persistence,
  no PDF export, no auth).

### MEDIUM

- **M1** — `justfile` with `check`, `test`, `fmt-check`, `stdio-probe`,
  `app-smoke`, `mcp-smoke`, `ci`, `build-release`, `installer`.
- **M2 (R4)** — `Command` enum + `Command::dispatch` in `sportscraft-core`; CLI,
  MCP, and UI all route through it.
- **M3** — `CHANGELOG.md` with 0.1.1 (this run) and 0.1.0.
- **M4** — `installer/installer.nsi` (current-user, `$LOCALAPPDATA`, Start Menu +
  desktop shortcuts, uninstall registry). Built and roundtripped (below).
- **M5** — `.gitignore` now covers `reports/`, `dist/`, `*.bak.*`.
- **M6** — `fatigue_weight_k2` default set to 1.0, so CTL/ATL/TSB share the TRIMP
  scale. The demo block now reports TSB −53.3 (honest: not race-ready), the UI shows
  the target window and colours the value red, and a regression test proves a
  21-day taper reaches ≥ +5.
- **M7** — 16 tests now: Banister identity, taper vs. detraining, optimal-window
  export, pacing scaling, invalid-distance rejection (0, negative, NaN), dispatch
  demo markers, MCP catalog count, alias equivalence, required `distance_m`,
  unknown-tool handling, and per-locale i18n strings.
- **M8** — added `LICENSE-MIT` and `LICENSE-APACHE` (canonical Apache text
  downloaded from apache.org).
- **M9 (R7)** — **not fixed** (see deferred).

### LOW

- Added `AGENTS.md`, `docs/DEVELOPMENT.md` (version convention, seam rules,
  add-a-capability recipe), `docs/TOOLS.md` (MCP schemas + CLI + UI).
- Removed unused dependencies **including the sibling-repo path dependencies**:
  the workspace now builds standalone. (This was a real portability defect, not
  cosmetic.)
- Deleted the stale `.gitignore` backup.
